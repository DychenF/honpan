运行说明

  1. 每个 A 股交易日 14:00（北京时间），后台任务列出当天候选股票；14:30 结合这之后30分钟的涨跌幅，自主决定全部买入、部分买入或放弃，并处理已有持仓的卖出判断。
  2. 决策综合技术面因子（涨跌幅、量能、走势）与公开可查的机构持仓线索（个股定期报告披露的十大流通股东中出现的量化私募/知名机构，作为参考信号之一）。
  3. AI 可以同时持有多只股票，也可以选择部分或全部空仓；每只股票的仓位比例由 AI 自行把控。买入的股票需遵守 T+1 规则。
  4. 每笔平仓交易都会扣除模拟的交易成本（参考华泰证券零售电子渠道典型费率估算：佣金双向万2.5、单笔最低¥5，印花税卖出单向千0.5，过户费双向万0.1；实际账户费率可协商，可能更低），历史记录里的盈亏都是扣除成本后的净值。
  5. 页面顶部的"累计收益率"= （历史已实现净盈亏 + 当前浮动盈亏）÷ 模拟本金，所有价格与盈亏均为模拟计算，不涉及真实资金、不对接真实券商账户。数据每次运行后通过 GitHub 更新，本页面每分钟自动刷新一次。
最后更新：暂无数据。行情数据来源：公开免费行情接口（新浪/东方财富等），可能存在延迟或中断；机构持仓线索来自季度定期报告等公开披露，存在滞后。
